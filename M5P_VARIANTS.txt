M5P installation profiles / M5P 설치 방식

Installation order: select FLEX4 M/L/W, then select:
1. Standard / 표준 버전 / 标准版
2. Auxiliary toolhead heating / 툴헤드 예열 보조 버전 / 工具头辅助加热版

Only M5P GitHub and Gitee distributions support this selection. M8P is unchanged.
The model Git branches remain FLEX4_M, FLEX4_L, FLEX4_W. Hardware profiles are
separate overlays; model motion coordinates are never copied from the test printer.
The standard model branches were not modified by this release.

The auxiliary profile matches the tested .97 software configuration:
- Existing PT1000 nozzle sensor PA1 (stock conversion, no pt1000_cal); Generic 3950 thermistor PA2, pull-up 4700 ohm.
- PB7 drives the DFR0457 heater interface, with a 24V 48W heater.
- Sensor presence replaces the standard PC3 toolhead presence input.
- Print docking arms auxiliary heating to the selected tool temperature;
  parking turns it off and confirms queued PWM is off before releasing the guard.
- Open-circuit detachment switches the auxiliary heater off at the first sample.
  Stable reconnection within five seconds restores the target only if the stored
  tool number is known/unchanged and no off/park/cancel or job change intervened.
  Unknown tool numbers and expired windows require a new heating command.
  Printing is paused, never automatically resumed. Temperature alone cannot
  authenticate the physical tool identity or distinguish a broken wire.
  Short-circuit, stale sensor and overtemperature protection remain active.
- Graph gaps and localized absence labels; titlebar shows '-' when detached.
- Maximum target 300 C, max_power 1.0, provisional reference PID.
  Thermal performance/PID must be validated on each hardware configuration.
- Manual preparation docking does not start heating automatically.

Updates retain the selected profile in ~/.local/share/lugoware/variant.json.
Mainsail system/config updates do not ask interactive questions and keep this choice.
To change hardware profile, run the normal SSH installer again and select it.
Legacy machines without a marker stay Standard. A recognized existing auxiliary
experiment keeps its wiring and limits; release PID is applied in auxiliary mode.

Selecting Standard removes the auxiliary configuration include, docking/parking
hooks and Mainsail extension, and reverses auxiliary UI changes. PC3 toolhead
presence is used again. Original PC3 sensor hardware is required for that function.
The inactive toolhead_auxiliary.cfg and unused module files may remain for recovery;
they are not loaded as heaters in Standard mode. Other calibration data is retained.

Backups are under ~/lugoware_backups/<install>/hardware-variant and related
variant-capture folders. manifest.json records each original path and numbered
backup; null means that file did not exist before. Do not restore during printing.
Installation errors are reported as failures, never as successful installation.
If a failure leaves an incomplete installation, inspect the installer log and retry
or restore the recorded files while the printer is idle.

Validation performed: all three current model profiles on both remotes; activation,
repeat installation, standard return, reactivation, unchanged motion coordinates,
configuration update overlay, UI patch reversal, write failure rollback, and
mock heater protection tests. No automatic heating/motion is run by profile selection.
Full physical installation and thermal tests on each model remain operator tests.

1.2.7 compatibility: known gettext quote styles and legacy Korean absence labels
are accepted. Package and retained UI checks run before system upgrades; older
screens scheduled for baseline replacement are checked after upgrade. Unknown
code changes still stop safely with the affected file and patch number.

1.2.8 introduced stock PT1000 for the nozzle; 1.2.9 also applies release PID values.
Retune PID after conversion changes. The unused calibration table may remain,
but is not selected by the auxiliary nozzle. Standard restores its sensor choice.
Nozzle SAVE_CONFIG sensor overrides are migrated without discarding PID data.

1.2.9: Auxiliary installs/updates enforce release PID, including SAVE_CONFIG:
nozzle Kp=13.953 Ki=0.511 Kd=95.230; auxiliary Kp=37.681 Ki=9.191 Kd=38.623.
These replace saved machine PID on auxiliary updates as requested. Standard and
bed remain unchanged. Measured on .107; validate thermal behavior on each unit.

1.2.10: Atomic profile writes stage in the unwatched backup directory on the
same filesystem, preventing duplicate Mainsail move-event rows. Byte-identical
files are skipped. No duplicate configuration files need to be deleted.

1.2.11: Explicit public-web 0644 permissions work under company UMask=0077.
Existing non-web modes are preserved; backups remain private. Failed writes
restore original file modes. Unchanged but unreadable web files are repaired.

﻿LUGOWARE 공장 출고 초기화 — 비밀번호 로그인 버전

1. ZIP 압축을 풀고 StartFactory.cmd를 실행합니다.
2. 프린터 IP(예: 192.168.0.151)를 입력합니다.
3. SSH 사용자 이름 biqu와 해당 프린터의 SSH 비밀번호를 입력합니다.
4. 원하면 '이 PC에 아이디·비밀번호 저장'을 체크합니다.
   저장하면 같은 Windows 계정에서 다음 실행부터 IP만 바꿔 연결할 수 있습니다.
   저장을 해제하면 보관된 인증정보가 삭제됩니다.
5. 연결 확인을 누르고 대상 프린터와 G-code 수·누적 출력 횟수를 확인합니다.
6. 프린터 초기화를 누르고 삭제 확인을 승인하면 실제 초기화가 실행됩니다.

개인키 파일은 필요 없습니다. Python이나 OpenSSH를 따로 설치할 필요도 없습니다.
FactorySSH.exe는 내부 연결 도우미이므로 직접 실행하지 마세요.
비밀번호는 명령줄에 넣지 않으며, 저장 시 Windows 계정으로 암호화합니다.
저장된 인증정보는 다른 PC나 다른 Windows 계정으로 옮겨 사용할 수 없습니다.

삭제: G-code·썸네일, 출력 이력·누적 통계·출력 큐,
복구 기록, 점검 결과, 관련 런타임 캐시, 저장된 모든 Wi-Fi 연결 정보,
접속·시스템 로그, 터미널 명령 기록, lugoware_backups·lugoware_m8p_backups 안의 설치 백업.
보존: 기구 설정, Z 오프셋·PID·메쉬 등 보정값,
유선 네트워크 설정, SSH 비밀번호·키, 펌웨어·업데이트 경로.

출력·일시정지·복구·점검 중이거나 히터 목표 온도가 켜져 있으면 초기화를 막습니다.
초기화가 완료되면 최초 언어 → 네트워크 → 시간대 설정 화면이 나옵니다.
출고할 때는 설정 완료를 누르지 말고 정상적으로 기기를 종료하세요.

각 프린터에서 최신 배포판의 SSH 설치 명령을 한 번 실행해야 합니다.
기존 메인세일 시스템 업데이트만으로는 새 관리자 권한이 등록되지 않습니다.
프로그램이 구버전 또는 관리자 도구 미설치를 알리면 SSH 설치부터 진행하세요.

초기화 전 다른 SSH 터미널을 종료하세요. 열린 터미널은 예전 명령 기록을 다시 저장할 수 있어 초기화를 차단합니다.
Wi-Fi 접속 정보는 공장 연결인지 구분할 수 없으므로 저장된 Wi-Fi 프로필 전체를 삭제합니다.
데이터 정리 후 20초 뒤 Wi-Fi 삭제가 시작됩니다. 그때 연결이 끊길 수 있습니다.
최소 1분 동안 전원을 유지하고, 스크린 네트워크에서 이전 Wi-Fi 저장 정보가 없는지 확인하세요.
유선 연결 시 /var/lib/lugoware-factory/privacy.json의 status가 complete인지 확인할 수 있습니다.
failed이면 초기화가 끝난 것으로 처리하지 말고 원인을 해결한 뒤 다시 실행하세요.
로그는 정리 후 정상적으로 새로 생성됩니다. 전문적인 저장장치 데이터 복구를 방지하는 보안 삭제는 아닙니다.
